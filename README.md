## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Requires Node.js >= 22.12.0.

## Testing

```bash
# Run tests
npm test

# Run tests with coverage
npm run test:coverage
```
